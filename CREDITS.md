# AAROGYA — Image Credits & Licensing

Every clinical image in this repo is **public domain or CC-licensed** so the
project can be published openly with zero licensing risk. Synthetic documents
(prescriptions, lab slips, ultrasound reports) are **canvas-rendered in-app** —
no real patient data anywhere.

> not as diagnostic references for any real patient.
